# گاهشمار سره — Sare Calendar

گاهشمار سرهٔ جلالی، کاملاً **ایستا** (بدون سرور): همه‌چیز در مرورگر کاربر اجرا می‌شود، پس
می‌تواند رایگان روی **GitHub Pages** میزبانی شود. رابط و نام‌ها تا جای ممکن پارسی سره‌اند.

## ویژگی‌ها

### گاهشمار
- نمای ماهانه‌ی جلالی با روزشمار ترسایی زیر هر روز؛ پیمایش ماه پیشین/پسین و کلید «برو به امروز».
- نام سنتیِ هر روز در گاهشماری زرتشتی (هرمزد تا انیران) و جشن‌های ماهانه‌ی ایرانی
  (فروردینگان، اردیبهشتگان، …، دی‌گان، بهمنگان، …).
- پنل جزئیاتِ روز: روزشمار جلالی، ترسایی و مهیِ (قمریِ جدولی) همان روز، رخدادها و یادداشت شخصی.
- روزهای فرویش (تعطیلی) با رنگ جدا؛ نقطه‌ی کوچک روی روزهای دارای رخداد و نقطه‌ی طلایی
  روی روزهای دارای یادداشت.
- ساعت ایران (`Asia/Tehran`) در سرصفحه، بر پایه‌ی ساعت دستگاه.
- «جمله‌ی امروز» (رخدادِ همان روز با توضیحش، یا یک جمله‌ی تاریخی-فرهنگی از مجموعه‌ی
  حدود ۳۰۰تایی) و «مثل روز» (حدود ۹۰ ضرب‌المثل فارسی)؛ برای هر روز ثابت‌اند.
- دادهٔ ۱۴۰۰ تا ۱۴۳۰.

### رخدادها
- **رخدادهای اصلی:** تاریخ و فرهنگ ایران، دانشمندان و هنرمندان، جشن‌های ایرانی، رخدادهای
  طبیعی (زمین‌لرزه‌ها، روزهای زیست‌بوم و کشاورزی) و روزها و رخدادهای میهنی و سیاسی.
  مناسبت‌های مذهبیِ اسلامی در این گاهشمار نیست.
- **رخدادهای نجومی** با ساعتِ دقیق ایران: تحویل سال و برابری‌های شب و روز، بلندترین روز و
  درازترین شب سال، کمترین و بیشترین فاصله‌ی زمین از خورشید، ماه‌گرفتگی و خورشیدگرفتگی (با
  یادکرد دیدنی‌بودن در ایران) و بارش‌های شهابیِ بزرگ.
- **لایه‌ی منطقه‌ای** (اختیاری): روز شیراز، اصفهان، کرمان، همدان، زنجان، بوشهر، مازندران و
  چهارمحال و بختیاری.
- **لایه‌ی جهانی** (اختیاری): روزهای جهانی و رخدادهای جهانیِ همان روزِ میلادی.
- رخدادهای دارای توضیح (نشانه‌ی ›) با زدن روی آن‌ها، توضیحِ چندجمله‌ای را در پنجره‌ی کوچکی نشان می‌دهند.

### ابزارها (منوی ☰)
| ابزار | کار |
|---|---|
| ترادیسیِ روزشمار | جلالی ↔ ترسایی ↔ مهی (قمریِ جدولی؛ ممکن است یک روز جابه‌جا باشد) |
| فاصله‌ی دو روزشمار و دیره | شمار روزها و همتای سال و ماه |
| جانور سال | گاهشماری دوازده‌جانوری (کمابیش) |
| شمارش وارونه | تا نوروز و تا نزدیک‌ترین فرویش |
| یادداشت‌ها | افزودن، زدایش، برون‌ریزی و درون‌ریزی (JSON)؛ فقط روی همین دستگاه |
| نمای سال | دوازده ماه یک سال در یک صفحه |
| هم‌رسانیِ امروز | هم‌رسانی یا رونوشتِ متن تاریخ و رخدادهای امروز |
| جست‌وجوی رخداد | یافتنِ روزهای دارای یک نام یا رخداد، و پرش به همان روز |
| واژه‌یاب سره | برابر پارسیِ بیش از ۲۰ هزار واژه‌ی بیگانه، با جست‌وجو و مرور الفبایی (پایگاه «پاسبان») |
| نام‌های پارسی | نام‌های پسرانه و دخترانه با ریشه‌ی ایرانی، همراه با معنی و ریشه؛ جست‌وجو در نام و معنی |
| تنظیمات | پوسته (روشن، تاریک، خودکار)، اندازه‌ی نوشته، لایه‌های رخداد، پاک‌کردن یادداشت‌ها، درباره |

### ظاهر و دسترسی
- پوسته‌ی روشن و تاریک (یا پیرو سیستم) بدون چشمک‌زدن هنگام بارگذاری.
- سه اندازه‌ی نوشته؛ چیدمان واکنش‌گرا برای موبایل.
- نصب‌شدنی (PWA) و کارکرد آفلاین با `manifest.json` و `sw.js`.
- فونت وزیرمتن به‌صورت محلی، بدون وابستگی به CDN.
- دسترسی با صفحه‌کلید (Enter/Space روی روزها).

## اجرا

### روی GitHub Pages
```bash
cd sare-calendar
git init && git add . && git commit -m "گاهشمار سره"
git branch -M main
git remote add origin https://github.com/<کاربری-شما>/sare-calendar.git
git push -u origin main
```
سپس در مخزن به **Settings → Pages** بروید و **Source** را روی **GitHub Actions** بگذارید.
ورک‌فلوی `.github/workflows/pages.yml` با هر push روی `main` سایت را منتشر می‌کند.

### اجرای محلی
```bash
python3 -m http.server 8000   # سپس: http://localhost:8000
```
(باز کردن مستقیمِ `index.html` ممکن است به‌خاطر محدودیت مرورگرها در واکشیِ فایل‌ها کار نکند.)

```
sare-calendar/

├─ assets/

│  ├─ events-data.js         رخدادها و فرویش‌های اصلی (۱۴۰۰–۱۴۳۰)

│  ├─ events-regional.js     لایه‌ی منطقه‌ای
│  ├─ events-global.js       لایه‌ی جهانی (کلید: ماه-روزِ میلادی)
│  ├─ event-context.js       توضیحِ پنجره‌ی رخدادها
│  ├─ history-facts.js, proverbs.js
│  ├─ persian-names.js       نام‌های پارسی با معنی، ریشه و شمارِ منابعِ تأییدکننده

│  ├─ icons/, fonts/, vendor/jalaali.js
├─ tools/
│  ├─ generate_events.py          ساخت events-data/regional/global از rokh
│  ├─ generate_natural_events.py  شمارش رخدادهای نجومی
│  ├─ persian-names.tsv           داده‌ی نام‌ها (ویرایش‌پذیر)
│  ├─ verify_persian_names.py     صحت‌سنجیِ نام‌ها با فهرست‌های باز
```

## به‌روزرسانیِ داده‌ها
دادهٔ پیش‌ساخته برای اجرای سایت کافی است. برای بازسازی یا گسترشِ بازه:
```bash
pip install rokh jdatetime astronomy-engine
python3 tools/generate_events.py            # رخدادها (قاعده‌ی گزینش بالای همین فایل است)
python3 tools/generate_natural_events.py    # رخدادهای نجومی
python3 tools/verify_persian_names.py       # صحت‌سنجیِ نام‌ها (نیاز به اینترنت و git)
python3 tools/build_persian_names.py        # ساخت دوباره‌ی persian-names.js
```
رخدادها از بستهٔ `rokh` گرفته می‌شوند؛ قاعده‌ی گزینش، لایه‌ها و پاکیزه‌سازیِ نوشته‌ها در
`tools/generate_events.py` است و با ویرایشِ همان فایل می‌توان آن را عوض کرد.

### نام‌های پارسی و صحت‌سنجی
نام‌ها در `tools/persian-names.tsv` (نام، گروه، معنی، ریشه) نگه‌داری می‌شوند. برای هر نام،
`verify_persian_names.py` می‌سنجد که در چند فهرست از چهار فهرستِ بازِ نام‌های ایرانی دیده می‌شود
و جنسیتِ ثبت‌شده با آن‌ها ناسازگار نیست، و معنی را با فهرستِ دارای معنی (BabyNames) هم‌سنجی می‌کند.
این سنجش وجودِ نام و هم‌خوانیِ معنی را می‌سنجد، نه ریشه‌شناسی؛ ریشه‌ها را باید با فرهنگ‌های
ریشه‌شناسی (دهخدا و مانند آن) هم‌سنجید. برای افزودن نام، یک سطر به فایل TSV بیفزایید و دو
اسکریپت آخر را اجرا کنید.

## درباره‌ی واژگان «سره»
نام ماه‌ها و روزها پارسی‌اند و واژگان رابط تا جای ممکن سره انتخاب شده‌اند («رخداد»، «فرویش»،
«ترادیس»، «رونگاری»، …). برای واژه‌های جاافتاده‌ای که برابرِ سره‌ی یکدستی ندارند، همان
واژه‌ی رایج به‌کار رفته است.
