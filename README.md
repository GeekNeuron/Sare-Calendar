# گاهشمار سره — Sare Calendar

گاهشمار سرهٔ جلالی، کاملاً به‌صورت **ایستا** (بدون هیچ سروری): همه‌چیز در مرورگر خودِ کاربر اجرا می‌شود
— برای همین می‌تواند مستقیماً روی **GitHub Pages** اجرا شود، رایگان و بدون بک‌اند.

## اجرای آنلاین روی گیت‌هاب (GitHub Pages)

۱. این پوشه را در یک مخزن (repository) تازه روی گیت‌هاب بارگذاری کنید:
```bash
cd sare-calendar
git init
git add .
git commit -m "نخستین نگارش گاهشمار سره"
git branch -M main
git remote add origin https://github.com/<کاربری-شما>/sare-calendar.git
git push -u origin main
```

۲. در مخزن، به مسیر **Settings → Pages** بروید و در بخش **Source** گزینه‌ی
   **GitHub Actions** را انتخاب کنید (نه «Deploy from a branch»).

۳. همین! ورک‌فلوی آماده در `.github/workflows/pages.yml` با هر push روی
   شاخه‌ی `main` سایت را می‌سازد و منتشر می‌کند. آدرس نهایی چیزی شبیه
   `https://<کاربری-شما>.github.io/sare-calendar/` خواهد بود.

> نیازی به Flask یا هیچ سرور پایتونی نیست — نسخه‌ی قبلی (Flask) برای اجرای محلی
> خوب بود، اما GitHub Pages فقط فایل ایستا (HTML/CSS/JS) اجرا می‌کند؛ برای همین
> منطق تبدیل تاریخ و نمایش را به‌طور کامل به جاوااسکریپت منتقل کردم و
> رخدادها را از پیش به یک فایل JSON تبدیل کردم.

## اجرای محلی (بدون گیت‌هاب)

چون سایت کاملاً ایستاست، کافی‌ست آن را با هر وب‌سروری سرو کنید؛ باز کردن مستقیم
`index.html` با دوبار-کلیک ممکن است به‌خاطر محدودیت مرورگرها در واکشی فایل
`data/events.json` کار نکند، پس یکی از این‌ها را اجرا کنید:

```bash
# با پایتون (از پیش روی همه‌ی توزیع‌های لینوکس هست)
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## ویژگی‌های تازه

- **ساعت ایران در هدر:** کنار «امروز»، ساعت لحظه‌ای بر پایه‌ی منطقه‌ی زمانی رسمی ایران
  (`Asia/Tehran`, UTC+۳:۳۰ ثابت — همان مبنایی که سایت time.ir از آن استفاده می‌کند) نمایش
  داده می‌شود. چون سایت کاملاً ایستاست و سروری در کار نیست، این ساعت از ساعتِ خودِ
  دستگاه کاربر محاسبه می‌شود، نه یک اتصال زنده به time.ir؛ اگر ساعت گوشی/کامپیوتر درست
  باشد، دقیقاً با آن یکی است.
- **بدون حالت «در حال بارگذاری»:** داده‌ی رخدادها و جمله‌های تاریخی به‌جای یک فایل JSON
  که با fetch واکشی شود، به دو فایل جاوااسکریپت (`assets/events-data.js` و
  `assets/history-facts.js`) تبدیل شدند که پیش از اجرای برنامه‌ی اصلی بارگذاری می‌شوند؛
  در نتیجه صفحه از همان لحظه‌ی اول با محتوای واقعی نمایش داده می‌شود.
- **موبایل:** رسپانسیو شد — هدر، ناوبری ماه و شبکه‌ی روزها در صفحه‌های باریک (زیر ۶۴۰ و
  زیر ۳۸۰ پیکسل) چیدمان و اندازه‌ی جداگانه دارند.
- **گزینش تاریخی، نه دولتی:** فهرست رخدادها به‌جای تکیه به هر چیزی که در تقویم رسمی
  ایران «روز نام‌گذاری‌شده» است، به‌دست دوباره گزینش شد تا بیشتر به سمت **تاریخ**
  (از ایران باستان تا پایان دوران پهلوی) سنگین باشد. جزئیاتش را در بخش «چگونه رخدادها
  گزینش شدند» پایین‌تر بخوانید.
- **جمله‌ی روز:** پایینِ تقویم، یک جمله یا رخداد کوتاه تاریخی/فرهنگی (از مجموعه‌ای حدود
  ۳۰۰ جمله در `assets/history-facts.js`) نمایش داده می‌شود — برای هر روز جلالی همیشه
  همان جمله ثابت است (نه هر بار تازه‌تصادفی)، اما روز به روز عوض می‌شود.
- **منوی ابزارها:** دکمه‌ی ☰ کنار عنوان یک ساید-منو باز می‌کند؛ هر ابزار از داخل آن به‌صورت
  یک پنجره‌ی مودال جداگانه اجرا می‌شود:
  - **تبدیل تاریخ** (جلالی↔میلادی)
  - **فاصله‌ی دو تاریخ و سن**
  - **حیوان سال تولد** (گاهشماری دوازده‌جانوری، تقریبی)
- **نام‌های روز به سره:** زیر شماره‌ی هر روز، نام سنتی همان روز در گاهشماری زرتشتی
  (هرمزد، بهمن، اردیبهشت، ... تا انیران؛ سی نام برای سی روز ماه) نیز نمایش داده می‌شود،
  و روزهایی که نام روزشان با نام ماه یکی می‌شود (مثل ششم خرداد) به‌عنوان جشن‌های
  دوازده‌گانه («جشن خردادگان» و مانند آن) مشخص شده‌اند.
- بدون کامنت راهنما در کدهای خودِ پروژه؛ سایه‌ی پیش‌فرض لمس/کلیک مرورگر خاموش شده؛
  تغییر ماه، باز/بسته‌شدن ساید-منو و مودال، و کارت جمله‌ی روز همگی انیمیشن نرم دارند.
- **ابزارهای تازه‌تر در همان منو:**
  - **تبدیل تاریخ** حالا هجری قمریِ تقریبی (گاهشماری جدولی، نه رؤیت‌هلال) را هم نشان می‌دهد.
  - **شمارش معکوس** تا نوروز و تا نزدیک‌ترین تعطیلی رسمی.
  - **یادداشت‌های شخصی** — یادآوری/سالگرد دلخواه اضافه کنید؛ فقط در `localStorage` همان
    مرورگر ذخیره می‌شود (هیچ سروری در کار نیست)، و روزهای دارای یادداشت یک نقطه‌ی طلایی
    روی تقویم می‌گیرند.
  - **نمای سال** — دوازده ماه یک سال را در یک صفحه، فشرده، کنار هم نشان می‌دهد.
  - **هم‌رسانیِ امروز** — متن تاریخ و رخدادهای امروز را با دکمه‌ی هم‌رسانی مرورگر (یا رونوشت) بفرستید.
- **پوسته‌ی تاریک:** دکمه‌ی ◐ کنار ساعت؛ انتخاب کاربر در `localStorage` می‌ماند و در
  بارگذاری بعدی، پیش از رنگ‌آمیزیِ صفحه اعمال می‌شود (بدون چشمک‌زدن).
- **نصب‌شدنی (PWA):** با `manifest.json` و `sw.js`، مرورگرهای پشتیبان امکان «افزودن به
  صفحه‌ی اصلی» و اجرای آفلاین را می‌دهند؛ آیکون‌ها در `assets/icons/` ساخته شده‌اند.
- **تقویمِ خلوت‌تر:** خانه‌های روز دیگر متن رخداد را داخل خودشان نشان نمی‌دهند — فقط یک
  نقطه‌ی کوچک (رخداد/یادداشت) و رنگ تعطیلی. با کلیک (یا اینتر/فاصله برای صفحه‌کلید) روی
  هر روز، جزئیاتش (روزشمار جلالی و ترسایی، نام روز در گاهشمار زرتشتی، رخدادها، یادداشت)
  در پنلی زیرِ خودِ تقویم باز می‌شود. با ورود به هر ماه، امروز (اگر در همان ماه باشد) یا
  روز یکم، پیش‌گزیده انتخاب شده است.

## پیرایش رابط کاربری (این نگارش)

- **هدر موبایل:** به دو ردیف ساده بازطراحی شد (ردیف بالا: منو/نام/پوسته، ردیف پایین:
  ساعت) تا در صفحه‌ی باریک از هم نپاشد؛ نشان «امروز: تاریخ» از هدر حذف شد چون همان
  اطلاعات همیشه در پنل روزِ زیرِ تقویم هم هست (با انتخاب پیش‌گزیده‌ی امروز).
- **رفع تداخل پوسته‌ی تاریک/روشن:** پس‌زمینه‌ی روزهای «فرویش» و پنل جزئیات روز که در
  پوسته‌ی تاریک هنوز رنگ روشن ثابت داشتند، حالا به متغیرهای رنگیِ سازگار با هر دو پوسته
  وصل شدند.
- **کلید پوسته:** آیکون خورشید/ماه، هردو با کد SVG دستی (نه اموجی)، با چرخش و محو نرم
  بین‌شان.
- **کلید «برو به امروز»:** فقط وقتی در ماه دیگری غیر از ماه جاری هستید نمایان می‌شود؛
  در حالت عادی با انیمیشن جمع می‌شود.
- **افزودن مهی (قمری):** روزشمار مهیِ همان روز، به‌صورت یک خط کوتاه در پنل جزئیاتِ
  زیرِ تقویم اضافه شد — نه در خودِ خانه‌های تقویم، تا شلوغ نشود.
- **ابزار «ترادیسیِ روزشمار» از نو ساخته شد:** حالا یک ابزار یکپارچه با سه زبانه
  (جلالی/ترسایی/مهی) است؛ هرکدام را پر کنید، نتیجه هر سه را با هم نشان می‌دهد.
- **فیلدهای مدرن‌تر:** فیلدهای سال/روز حالا یک استپر با دکمه‌ی + / − دارند و فیلد ماه
  یک منوی کشویی با نام ماه‌هاست (به‌جای ورودی خام عددی) — در همه‌ی ابزارها یکدست شد.
- **سایه‌ی کلیک/تاچ:** به‌طور کامل خاموش است (`tap-highlight-color: transparent` +
  حذف outline پیش‌فرض روی همه‌ی دکمه‌ها/ورودی‌ها).
- **سایه‌ی پنجره‌ی مودال و ساید-منو:** در پوسته‌ی روشن سایه‌ی تیره، در پوسته‌ی تاریک
  یک هاله‌ی نرمِ سفید — تا از پس‌زمینه متمایز بمانند.
- **انیمیشن:** به بیشتر اجزایی که نداشتند اضافه شد — نقطه‌های رخداد/یادداشت، ردیف‌های
  فهرست یادداشت، ماه‌های کوچکِ نمای سال، ورودی/خروجی کلید «برو به امروز»، و تغییر نرمِ
  رنگ‌ها هنگام سوییچ پوسته.

## چگونه رخدادها گزینش شدند

فهرست خام رخدادهای بستهٔ `rokh` («جلالی») حاوی صدها مورد است: از تاریخ باستان تا
روزهای اداری/بوروکراتیکِ امروزی (مثل «روز ملی X») و مناسبت‌های سیاسی-مذهبیِ
جمهوری اسلامی. برای این پروژه، این فهرست را دستی از نو گزینش کردم — نه با فیلترِ
خودکارِ کلیدواژه‌ای، بلکه با مرور تک‌تکِ ۴۷۷ مدخل و نگه‌داشتن حدود ۱۶۵ موردِ زیر:

**نگه داشته شد:**
- شخصیت‌های تاریخی/علمی/ادبی/هنری ایران — از دوران باستان تا امروز — تا زمانی که
  چهره‌ای سیاسی یا روحانیِ وابسته به حکومت نبودند (فردوسی، حافظ، ابن سینا، مریم
  میرزاخانی، انوشه انصاری، محمدرضا شجریان، و مانند آن‌ها)
- رویدادهای بزرگ تا پایان دوران پهلوی (فتح بابل به دست کوروش، انقلاب مشروطه، کودتای
  ۲۸ مرداد، ملی‌شدن نفت، اشغال ایران در جنگ جهانی دوم، و…)
- جشن‌های باستانی (نوروز، سیزده‌به‌در، یلدا، سده، سپندارمذگان، …)

**حذف شد:**
- هر چیز مرتبط با رهبران و نهادهای جمهوری اسلامی، انقلاب ۵۷، جنگ ایران‌وعراق (با
  چارچوب‌بندی «دفاع مقدس»)، روحانیونِ وابسته به حکومت پس از ۱۳۵۷، تسخیر سفارت، و مانند آن —
  حتی اگر رسماً تعطیل رسمی باشند (مثل ۲۲ بهمن یا رحلت امام خمینی، که دیگر در تقویم رنگ
  تعطیلی هم نمی‌گیرند)
- روزهای عمومیِ بوروکراتیک بدون هیچ شخصیت یا رویداد مشخص (روز دندانپزشک، روز بیمه، …)
  تا شلوغیِ تقویم کم شود
- بلایای طبیعی و حوادثِ مدرن (زلزله، سقوط هواپیما، آتش‌سوزی) — به‌جز دو زلزله‌ی پیش از
  ۱۳۵۷ (بویین‌زهرا، فردوس) که به‌عنوان تاریخ نگه داشته شدند

منطق دقیق گزینش (فهرست ۱۶۵ موردیِ نگه‌داشته‌شده) در بالای فایل
`tools/generate_events.py`، در متغیر `ALLOWED_EVENTS`، قابل مشاهده و ویرایش است.
اگر مورد خاصی را کم یا زیاد می‌خواهید، همان فهرست را دستی ویرایش کنید و اسکریپت را
دوباره اجرا کنید — این‌جا قضاوت سلیقه‌ای دخیل بوده و طبیعتاً جای بحث دارد.

## دیتابیس واژگان سرهٔ «پاسبان» — پیاده شد

دیتابیس [`keyaruga33/pasban_db`](https://github.com/keyaruga33/pasban_db) واقعاً
در پروژه پیاده شده — نه فقط ارجاع بهش:

- تمام ۲۰٬۱۹۴ ردیفِ «واژه‌ی بیگانه ↔ برابر پارسی» از فایل SQLite رسمی‌شان گرفته و به
  `assets/pasban-words.js` تبدیل شده (اسکریپت تولیدش: `tools/generate_pasban_words.py`).
- یک ابزار تازه در منو، **«واژه‌یاب سره»**، هر واژه‌ای را که بنویسید در همین دیتابیس
  می‌جوید و برابر پارسی‌اش را نشان می‌دهد — کاملاً آفلاین، بدون نیاز به اینترنت.
- واژگان رابط‌کاربریِ خودِ برنامه هم با همین دیتابیس بازبینی و تا حد امکان سره شدند:
  میلادی→ترسایی، تبدیل→ترادیسی، تاریخ (به‌معنای یک روز)→روزشمار، حیوان→جانور،
  معکوس→وارونه، تعطیل→فرویش، متن→نوشته، حذف→زدایش، معتبر→پای‌مند، محاسبه→شمارش، و مانند آن.
- طبق شرط مجوز پاسبان، نامش همه‌جا که از داده‌اش استفاده شده قید شده — در ابزار
  «واژه‌یاب سره» و در فوتر همان صفحه.

**آن‌جاهایی که عمداً واژه‌ی رایج را نگه داشتم:** وقتی برابر پیشنهادیِ دیتابیس معنای
دیگری از همان واژه را هدف گرفته بود (مثلاً «تاریخ» به‌معنای «گذشتار/تاریخ‌نگاری»، نه
«یک روز مشخص») یا آن‌قدر ناآشنا بود که ممکن بود کارکردِ خودِ تقویم را گنگ کند
(مثلاً برای «رسمی» یا «جشن»)، همان واژه‌ی رایج را نگه داشتم تا بین سره‌نویسی و
خواناییِ ابزار، یک تعادل بماند. اگر ترجیح می‌دهید حتی این‌ها هم عوض شوند، بگویید.

```
sare-calendar/
├─ index.html                  صفحه‌ی اصلی
├─ manifest.json               مانیفست PWA (نصب‌شدن روی موبایل/دسکتاپ)
├─ sw.js                       سرویس‌ورکر برای اجرای آفلاین
├─ assets/
│  ├─ style.css                استایل (رنگ‌بندی الهام‌گرفته از کاشی‌کاری ایرانی) + پوسته‌ی تاریک
│  ├─ app.js                   منطق گاهشمار، ساعت ایران، ابزارها، یادداشت‌ها، پوسته
│  ├─ events-data.js           رخدادها/تعطیلی‌های از پیش تولیدشده (۱۴۰۰ تا ۱۴۳۰)، بدون متن مناسبت‌های قمری
│  ├─ history-facts.js         نزدیک به ۳۰۰ جمله/رویداد کوتاه تاریخی-فرهنگی
│  ├─ pasban-words.js          بیش از ۲۰هزار واژه‌ی بیگانه با برابر پارسی (از پایگاه‌داده‌ی پاسبان)
│  ├─ icons/                   آیکون‌های PWA (۱۹۲ و ۵۱۲ پیکسل)
│  ├─ fonts/                   فونت وزیرمتن، دانلود و بومی‌سازی‌شده (بدون وابستگی به CDN)
│  └─ vendor/jalaali.js        کتابخانه‌ی تبدیل جلالی↔میلادی (jalaali-js، MIT)
├─ tools/
│  ├─ generate_events.py       تولید دوباره‌ی events-data.js (نیاز به پایتون، فقط برای توسعه)
│  └─ generate_pasban_words.py تولید دوباره‌ی pasban-words.js از روی دیتابیس رسمی پاسبان
└─ .github/workflows/pages.yml انتشار خودکار روی GitHub Pages
```

## به‌روزرسانی داده‌ی رخدادها

فایل `assets/events-data.js` از پیش تا سال ۱۴۳۰ تولید شده و برای اجرای سایت لازم نیست
دوباره چیزی اجرا کنید. اگر خواستید بازه را گسترش دهید یا داده را به‌روز کنید:

```bash
sudo apt install -y python3 python3-pip
pip install rokh jdatetime --break-system-packages
python3 tools/generate_events.py
git add assets/events-data.js && git commit -m "به‌روزرسانی داده‌ی رخدادها"
```

اگر خواستید مناسبت‌های قمری/مذهبی هم دوباره در فهرست متنی نمایش داده شوند، در تابع
`main` این اسکریپت، خط ساخت `events` را طوری تغییر دهید که رشته‌های
`info["events"]["hijri"]` را هم به فهرست اضافه کند.
