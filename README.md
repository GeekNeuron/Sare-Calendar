# تقویم سره — Sare Calendar

تقویم سرهٔ جلالی، کاملاً به‌صورت **ایستا** (بدون هیچ سروری): همه‌چیز در مرورگر خودِ کاربر اجرا می‌شود
— برای همین می‌تواند مستقیماً روی **GitHub Pages** اجرا شود، رایگان و بدون بک‌اند.

## اجرای آنلاین روی گیت‌هاب (GitHub Pages)

۱. این پوشه را در یک مخزن (repository) تازه روی گیت‌هاب بارگذاری کنید:
```bash
cd sare-calendar
git init
git add .
git commit -m "نخستین نگارش تقویم سره"
git branch -M main
git remote add origin https://github.com/<کاربری-شما>/sare-calendar.git
git push -u origin main
```

۲. در مخزن، به مسیر **Settings → Pages** بروید و در بخش **Source** گزینه‌ی
   **GitHub Actions** را انتخاب کنید (نه «Deploy from a branch»).

۳. همین! ورک‌فلوی آماده در `.github/workflows/pages.yml` با هر push روی
   شاخه‌ی `main` سایت را می‌سازد و منتشر می‌کند. آدرس نهایی چیزی شبیه
   `https://<کاربری-شما>.github.io/sare-calendar/` خواهد بود.

> نیازی به Flask یا هیچ سرور پایتونی نیست — نسخه‌ی قبلی (Flask) برای اجرای محلی
> خوب بود، اما GitHub Pages فقط فایل ایستا (HTML/CSS/JS) اجرا می‌کند؛ برای همین
> منطق تبدیل تاریخ و نمایش را به‌طور کامل به جاوااسکریپت منتقل کردم و
> رخدادها را از پیش به یک فایل JSON تبدیل کردم.

## اجرای محلی (بدون گیت‌هاب)

چون سایت کاملاً ایستاست، کافی‌ست آن را با هر وب‌سروری سرو کنید؛ باز کردن مستقیم
`index.html` با دوبار-کلیک ممکن است به‌خاطر محدودیت مرورگرها در واکشی فایل
`data/events.json` کار نکند، پس یکی از این‌ها را اجرا کنید:

```bash
# با پایتون (از پیش روی همه‌ی توزیع‌های لینوکس هست)
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## ساختار پروژه

```
sare-calendar/
├─ index.html              صفحه‌ی اصلی
├─ assets/
│  ├─ style.css            استایل (رنگ‌بندی الهام‌گرفته از کاشی‌کاری ایرانی)
│  ├─ app.js                منطق گاهشمار (تبدیل تاریخ، رخدادها، ناوبری ماه)
│  ├─ fonts/                فونت وزیرمتن، دانلود و بومی‌سازی‌شده (بدون وابستگی به CDN)
│  └─ vendor/jalaali.js     کتابخانه‌ی تبدیل جلالی↔میلادی (jalaali-js، MIT)
├─ data/events.json         رخدادها/تعطیلی‌های از پیش تولیدشده (۱۴۰۰ تا ۱۴۳۰)
├─ tools/generate_events.py اسکریپت تولید دوباره‌ی events.json (نیاز به پایتون دارد، فقط برای توسعه)
└─ .github/workflows/pages.yml   انتشار خودکار روی GitHub Pages
```

## به‌روزرسانی داده‌ی رخدادها

فایل `data/events.json` از پیش تا سال ۱۴۳۰ تولید شده و برای اجرای سایت لازم نیست
دوباره چیزی اجرا کنید. اگر خواستید بازه را گسترش دهید یا داده را به‌روز کنید:

```bash
sudo apt install -y python3 python3-pip
pip install rokh jdatetime --break-system-packages
python3 tools/generate_events.py
git add data/events.json && git commit -m "به‌روزرسانی داده‌ی رخدادها"
```

## فونت

فونت **وزیرمتن** (طراحی صابر راستی‌کردار، مجوز SIL Open Font License 1.1) به‌صورت
فایل‌های `woff2` مستقیماً در `assets/fonts/` قرار گرفته — دیگر نیازی به اتصال به
CDN بیرونی نیست و سایت کاملاً مستقل (self-contained) است. متن مجوز در همان پوشه،
فایل `VAZIRMATN-LICENSE-OFL.txt` موجود است.

## درباره‌ی واژگان «سره»

نام ماه‌ها (فروردین..اسفند) و شمارش هفته از پیش پارسی‌اند. واژگان رابط کاربری هم
تا جای ممکن سره انتخاب شده‌اند («گاهشمار» به‌جای «تقویم» در نام‌گذاری داخلی،
«رخداد» به‌جای «ایونت»)، هرچند نام نهایی پروژه («تقویم») به درخواست شما نگه
داشته شد. برای واژه‌های جاافتاده‌ای مثل «تعطیل رسمی» معادل سره‌ی یکدست و رایجی
در زبان امروز وجود ندارد؛ اگر معادل دلخواهی دارید (مثلاً نام‌های اوستایی/پهلوی)
بگویید تا در نگارش بعدی جای‌گذاری شود.
